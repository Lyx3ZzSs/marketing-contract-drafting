## 阅读比例与快速翻页优化（2026-11-02）

默认缩放由整页显示改为适合宽度，已有手动选择的缩放和阅读位置继续保留。当前 PDF 转换已切换 ONLYOFFICE，见相邻 `onlyoffice/README.md`；前面的 LibreOffice 内容是历史验收记录。

根因与修复：

- 原 IntersectionObserver 以浏览器视口为根，预加载范围受中间滚动容器裁切。现在正文与缩略图分别以自己的滚动容器为根，提前渲染上下至少 500px、通常一屏的内容。
- 原页面离开预加载区立即清空画布，返回时重新渲染。现在保留最近完成的页面，同一文件、页码、缩放直接复用。
- 原缩放在可见画布上重新设置尺寸并绘制，会先清空旧画面。现在使用独立画布和文字层，全部完成后一起替换；等待期间按新尺寸缩放旧画面。过期异步任务不能覆盖新画面，切换文件会立即清除旧文件内容。
- 完成页面的位图缓存预算为 96 MiB，优先淘汰远处旧页；可见和预加载页受保护，因此这不是整个预览器的硬内存上限。单页位图约限制在 800 万像素，关闭页面释放缓存及待完成缓冲。滚动状态更新按动画帧合并。
