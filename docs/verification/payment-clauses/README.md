## 实现规则

- 同一合同所有已填写标的的节点及比例必须一致；未填写标的不参与比较。比较与生成仅使用节点 ID 和比例，不使用弹窗天数、到期信息。
- 全部留空时保留原文；有统一计划时，未采用节点填 0%、0.00、零圆整。
- 后端使用 Decimal 计算金额。前序款项四舍五入到分、末个有比例的节点承接尾差；极小合同金额受剩余额度约束，不产生符号反转的尾款。
- 比例冲突时页面返回具体标的提示，PDF 创建接口返回 422，不使用旧缓存或任意一条设置。
- 映射版本升级为 `wind-purchase-v2-payments`，只适用于已适配模板 SHA；原有手工编辑权限继续关闭。
